## Concept

Race cyberpunk wolves through neon synthwave worlds where **every obstacle is synced to
the soundtrack**. Morph between wolf forms — each form is a distinct game mode — as you
run, jump, and ride the beat. Five worlds, eight game modes, and a built-in level editor
so the community can build and share its own tracks.

## Design Pillars

1. **Rhythm-synced obstacles** — the level *is* the music. Jumps, hazards, and camera
   hits land on the beat; the soundtrack drives level design, not the other way around.
2. **Wolf-morph game modes** — swapping wolf form mid-run changes how you play
   (Geometry-Dash-style mode shifts: runners, flyers, climbers, and more).
3. **Synthwave soundtrack** — an original synthwave score with per-world sonic identity;
   audio-reactive visuals throughout.
4. **Level editor + community sharing** — a first-class in-game editor with one-click
   publishing and browsing of community-made levels. Sharing is core to the game, not an
   afterthought.

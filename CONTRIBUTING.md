# Contributing

Thanks for your interest in Cyber Wolf Dash! The game is in **pre-production**, and the
repo currently hosts design docs and project scaffolding — game code comes later. Here's
how you can be involved now and once development ramps up.

## What you can contribute now

- **Feedback on the public design docs** — [docs/GDD-OUTLINE.md](docs/GDD-OUTLINE.md)
  and [docs/ROADMAP.md](docs/ROADMAP.md). Open an issue with ideas, concerns, or
  "would love to see" suggestions for worlds, modes, or the level editor.
- **Community levels (later)** — level sharing is a core feature. Once the editor
  alpha ships, in-editor creation and sharing will be the main way to contribute
  content. Editor-format level submissions to this repo will be welcome, with credit.

## What's not open for contribution

- **Game source code, art, and music.** Cyber Wolf Dash is a proprietary, commercial
  product (© SOETech LNM). This is a public repo, not an open-source project — we share
  progress, not the codebase. PRs touching game code will be closed. (The Godot engine
  itself is MIT — that's the engine's license, not ours.)

## Ground rules

- Check existing issues/discussions before opening a new one
- One idea per issue; be specific
- Be constructive and follow the [Code of Conduct](CODE_OF_CONDUCT.md)
- Keep shared content family-friendly and original (or properly credited)

## Bug reports (once builds exist)

When playable builds ship, include: build version, platform, steps to reproduce,
expected vs actual behavior, and a video/clip if it's a rhythm-sync timing issue
(timing bugs are our #1 priority class).

— The SOETech LNM team
